## 简介（可直接复制）

```
一句话需求 → 一个可以直接在浏览器里跑起来的 3D 场景。
人类没有编写、没有修改任何一行代码。

【这是什么】
用 Three.js 做的程序化 3D 场景：一只鹈鹕在荒野公路上骑自行车。
全部内容——鹈鹕、自行车、地形、道路、湖泊、树木、云、光照、动画、交互——
都是运行时用 JavaScript 现算出来的：

· 没有 3D 模型文件（glTF/OBJ 都没有）
· 没有贴图、没有 SVG、没有 2D Canvas
· 没有预渲染动画，也没有骨骼动画文件
· 整个项目就是一个 1780 行、80 KB 的 index.html

【骑行是"算"出来的，不是"摆"出来的】
· 车轮角速度 ω = v/R，曲柄角速度 = 车轮 × 齿比(16/42)
  → 6.2 m/s 巡航时踏频正好 66 rpm
· 双腿用双骨 IK 实时反解，脚踝始终锁在脚踏上表面，膝盖随行程屈伸
· 双翼同样用 IK 锁在车把握把上，转向时翅膀跟着车把走
· 前轮绕真实头管轴偏转，转向角 = atan(轴距 × 曲率)
· 过弯自动侧倾，侧倾角 = atan(v²κ/g)，与真实骑行一致
· 身体起伏、颈部摆动、喉囊抖动都与踏频耦合

【场景里还有什么】
解析式起伏地形、随地形起伏的公路与中央虚线、带波浪的湖面、
实例化的树/灌木/石头/草丛、飘动的云、天上的雁群、
逐顶点着色的天空、日月与星空、5:00–21:00 时刻系统（光色/雾/阴影/曝光联动）。

【交互】
6 种机位（跟随/环绕/电影/正面/低角/特写）、拖拽环绕、滚轮缩放、
方向键变线、↑↓ 调速、空格刹车、C 切机位、
点击鹈鹕会鸣叫（喉囊充气，声音由 WebAudio 实时合成，没有音频文件）。

【关于"一次性生成"】
这是一次模型能力测试：只给了一条中文需求，没有追问、没有人工补写代码。
模型自己搭了一套"眼睛"——用无头 Chrome 截图回读，逐轮发现并修掉了 11 个缺陷
（太阳位置错了、羽毛朝向反了、喉囊太小、加载页永不消失……），
完整过程记录在仓库的 docs/TEST-REPORT.md 里。

【在线体验 / 源码】
🔗 https://wulusai2333.github.io/pelican-cyclist/
⭐ https://github.com/wulusai2333/pelican-cyclist

【说明】
本片由脚本驱动无头 Chrome 录制，配乐与鸣叫均由代码实时合成（无版权素材）。
录制环境是 SwiftShader 软件渲染，因此片中帧率不代表真机表现；
真实 GPU 上场景约 140 个绘制批次，可满帧运行。
本视频画面与代码均由 AI 生成。
```
